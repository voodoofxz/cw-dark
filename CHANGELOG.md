# Changelog

## 1.4.2
- Added: Homepage link on the extensions page now opens the project on GitHub.

## 1.4.1
- Fixed: errors logged when the extension was updated or reloaded while ConnectWise tabs were open.

## 1.4.0
- Added: export status highlights to a file and import them on another browser.

## 1.3.1
- Fixed: "Add this site" in the popup didn't save the site after access was granted.
- Changed: popup link renamed to "Manage settings".

## 1.3.0
- Added: Dark / Light theme toggle. Status highlights work in both themes.
- Added: Alt+Shift+D keyboard shortcut to switch themes.

## 1.2.0
- Added: wildcards in status highlights (`*` any characters, `?` one character).
- Changed: when a status matches several entries, the one highest in the list wins.

## 1.1.1
- Fixed: highlights could match non-status text such as the "+ New" menu. Matching now only uses the Status column.

## 1.1.0
- Added: status highlights — color, stripe and bold ticket rows by status (default: Client Responded).
- Added: areas ConnectWise already draws dark, like the left navigation bar, stay dark.

## 1.0.0
- Initial release: dark mode for ConnectWise PSA on sites you add, brightness and contrast controls, original-color images, custom CSS.
