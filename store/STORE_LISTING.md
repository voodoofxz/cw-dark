## Description

Easier on the eyes during long days in ConnectWise PSA. This extension adds a dark theme to ConnectWise PSA (Manage) and lets you color-code tickets by status, so the ones that need attention stand out on any service board.

Dark theme
• Works on ConnectWise cloud (na/eu/au.myconnectwise.net) and self-hosted sites. You add your site, and the extension runs only there.
• Areas that are already dark, like the left navigation bar, stay dark.
• Logos and images keep their original colors.
• Adjustable brightness and contrast.
• Switch between Dark and Light from the toolbar or with Alt+Shift+D.

Status highlights
• Tint, stripe and bold ticket rows by status. "Client Responded" is set up by default.
• Pick any color for each status.
• Wildcards: "New*" matches New, New (email) and New (portal).
• Works in both Dark and Light themes.
• Export your highlights to a file and share them with your team.

Custom CSS
Advanced users can add their own CSS in the extension's settings. Custom CSS is used at your own risk. Support covers the extension's built-in features and settings only; I can't troubleshoot custom CSS or problems it causes. If something looks wrong, clear the Custom CSS box first to see whether the issue comes from the extension itself.

Privacy
The extension only runs on sites you add, and it asks for access to each one. It collects no data and sends nothing anywhere. Your settings are saved in your browser and sync through your browser profile.

## Privacy / permission answers
Single purpose:
Applies a dark theme and status-based row highlighting to ConnectWise PSA pages.

storage:
Saves the user's sites, theme and highlight settings.

scripting:
Applies the theme and highlights only on sites the user has added.

activeTab:
Lets "Add this site" read the current tab's address when the user clicks it.

Host permissions:
Requested one site at a time, only for ConnectWise sites the user adds. No sites are accessed until the user adds and approves them.

Remote code: No, the extension does not use remote code.

Data usage: No user data is collected. Certify that data is not sold, not used for unrelated purposes, and not used for creditworthiness.
