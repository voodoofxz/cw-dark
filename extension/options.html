    Status highlights

    Tickets in these statuses are tinted and bolded in ticket lists and service boards. Type the status as it appears in ConnectWise; capitalization doesn't matter. Use * for any characters and ? for a single character, so New* matches New, New (email) and New (portal). If a status matches more than one entry, the one higher in the list wins.

    Export saves this list as a file you can send to a coworker. Import adds a file's statuses to your list, replacing colors for statuses you already have; review the list, then save.

      Custom CSS

      For spot fixes. Dark mode works by inverting the page, so to make something look darker here, give it a lighter color. To show an element in its true colors, add filter: invert(1) hue-rotate(180deg).
